## 📖 Описание

**RMRP Bot** — программа, которая автоматизирует рыбалку и работы в RMRP (DLC на рыбалку и работы). Статистику фарма можно смотреть в Telegram.

### ✨ Возможности

#### 🎣 Автоматическая рыбалка
- 🟢 Ловит рыбу
- 🟢 Когда рыба в зоне улова заканчивается, присылается уведомление в Telegram

#### 🍄 Помощник для сбора грибов
- Жмёт `E` и проходит мини-игру

#### 🔎 Помощник в поиске кладов
- Автобег + `Alt` — вам надо только мышкой крутить

#### 📊 Telegram-статистика
- Статистика фарма в Telegram

### 🚀 Быстрый старт

1. Приобретите ключ на [официальном сайте](#-где-приобрести)
2. Скачайте и запустите программу
3. Введите лицензионный ключ
4. Выберите нужные функции и подключите Telegram для статистики
